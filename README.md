# Breinpotentieel

Een Nederlandstalige, interactieve leergids over neurale capaciteit, netwerkcapaciteit, plasticiteit en de fysiologische processen en gewoontes die ze ondersteunen. De afzonderlijke verdiepingspagina behandelt de moleculaire architectuur van neuronen, synaptische communicatie en de functionele architectuur van het brein.

De site is volledig statisch. Open `index.html` lokaal of publiceer de repository via GitHub Pages.
